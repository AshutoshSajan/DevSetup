What do you build?

Pick one or more roles. The tool list follows your choice.

Choose your tools

Cleaner

Free disk space. Sizes are estimates, and nothing is deleted until you press Clean.

Updates

Update system packages and the tools you installed. Nothing changes until you press Update.
Each item updates everything of its kind on this machine, not only tools from DevSetup's list.

Doctor

Checks that your tools run and your setup is healthy, with fixes. Checks only read; nothing changes until you press a fix.

Git and GitHub

Set up your identity, an SSH key, GitHub sign-in and signed commits. Every step is optional and only touches your own settings.

Shell setup

Add a prompt, plugins, history settings and aliases to zsh or bash. DevSetup only edits one marked block, backs up your original file once, and can remove the block again.

VS Code extensions

Install extension packs for your roles. Packs for the roles you picked in Setup are ticked. Extensions install one at a time with the editor's own command line.

Review plan

System packages are installing and cannot be stopped safely. Cancel takes effect when they finish.
